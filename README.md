# Dmitry Bozhko Portfolio

Welcome to my personal portfolio website!  
Built with React, Framer Motion, and Tailwind CSS, this project showcases my background, skills, and selected projects.

🔗 **Live site:** [https://dmitrybozhko.com](https://dmitrybozhko.com)

---

## 🚀 Features

- Clean, responsive UI built with **React** and **Tailwind CSS**
- Animated transitions via **Framer Motion**
- Contact form powered by **Formspree**
- Fully responsive and mobile-friendly
- Deployed via **Vercel**

---

## 🛠 How to Run This Project Locally

### 1. Clone the Repo

```bash
git clone https://github.com/DmitryBozhko/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Dev Server

```bash
npm run dev -- --host
```

> `--host` lets you view the site on other devices in your local network (e.g., your phone or tablet)

### 4. Build for Production

```bash
npm run build
```
